Icon Vectorizer

Convert PNG/JPG jadi SVG full color. Self-hosted, nggak ada limit akun.

Gambar dengan gradasi/shading atau format JPEG gampang "pecah" jadi banyak path kecil. Kalau masih pecah: turunin Color Precision lebih rendah, naikin Filter Speckle lebih tinggi.

Pakai API resmi Vectorizer.ai. Butuh API ID + API Secret yang di-set sebagai environment variable VECTORIZER_API_ID dan VECTORIZER_API_SECRET di Netlify (Site settings → Environment variables), diambil dari akun vectorizer.ai lo. Mode "test" gratis buat nyoba tapi hasilnya ada watermark; "production" motong kredit beneran.
